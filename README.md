# China-US Global Intelligence Radar

一个面向个人研究使用的 OSINT 情报雷达仪表盘。

## 监测范围
- 中国：金融经济、军事、内政、安全、政策
- 美国：金融经济、军事、内政、安全、政策
- 中美战略竞争：贸易、科技、投资、供应链、外交与军力
- 全球：地缘政治风险、全球化、冲突、能源安全与关键航运

## 架构
静态网页 + `data/news.json` 数据层 + GitHub Actions 自动采集/更新。网页本身不需要服务器。

> 当前提交包含 UI 与演示数据。下一步接入新闻/RSS/GDELT 等公开信息源，以及 GitHub Actions 的每日自动更新流程，并对来源、发布时间、重复新闻和风险评分进行规范化处理。
