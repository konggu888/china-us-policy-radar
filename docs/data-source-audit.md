# 数据源审计与接入路线

更新时间：2026-09-19

## 当前结论

现有项目已经有新闻、官方页面、RSS、市场行情、新闻归档和情景状态，但**结构化宏观、贸易、政策法规、供应链、企业行为数据仍明显不足**。

### P0：先补齐

1. 中国正式政策原文
2. 美国正式政策/法规原文
3. 中国宏观时间序列
4. 美国宏观时间序列
5. 核心金融市场时间序列
6. 中美商品级贸易数据
7. 所有P0指标的历史快照

### P1：第二阶段

- 供应链/物流
- 关键原材料
- 30-50家关键企业行为
- 第三方国家贸易转移

## 关键设计原则

- 新闻只是事件发现层，不是所有指标的事实来源。
- 正式政策与新闻稿分层。
- 市场价格与实体经济数据分层。
- 每个数据点保存来源、时间、单位、频率和历史版本。
- 历史窗口缺数据就保持MISSING，绝不拿当前数据回填过去。
- 多源冲突不静默覆盖。
